== Description ==
Exsit is a modern, fast, and highly customizable WordPress theme built for SaaS startups, business websites, landing pages, blogs, and portfolio websites. Exsit features clean UI, responsive layouts, and performance-optimized structure for great Core Web Vitals.

The theme supports Elementor (free), Gutenberg, and includes flexible layout options for blog, pages, and single posts. Exsit is fully responsive and works beautifully across desktops, tablets, and mobile devices.

You can build a professional website quickly with Exsit’s prebuilt layouts and customization options.


== Installation ==

1. In your admin panel, go to Appearance > Themes.
2. Click Add New > Upload Theme.
3. Choose the theme ZIP file and click Install Now.
4. Activate the theme.

== Requirements ==
- WordPress 5.8 or higher
- PHP 7.4 or higher

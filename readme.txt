== Description ==
Exsit is a high-performance, modern WordPress theme designed for SaaS startups, tech businesses, and creative portfolios. Built with a focus on Core Web Vitals and speed, Exsit provides a seamless experience for both developers and end-users.

The theme is deeply integrated with Elementor, offering custom-built widgets via the Exsit-Core plugin. With support for Gutenberg, WooCommerce, and various layout styles (left/right sidebars, full-width), Exsit is as flexible as it is fast.

== Installation ==

1. In your admin panel, go to Appearance > Themes.
2. Click Add New > Upload Theme.
3. Choose the theme ZIP file (exsit.zip) and click Install Now.
4. Once installed, click Activate.
5. Follow the TGM Plugin Activation prompts to install required plugins.

== Requirements ==
- WordPress 6.0 or higher (Updated for better Block Editor support)
- PHP 7.4 or higher (8.1+ Recommended)
